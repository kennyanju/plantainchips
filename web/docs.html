01 / Model Context Protocol (MCP) Setup
Claude Desktop · Cursor · Windsurf · Gemini CLI Integration

Add CloudSecure tools directly to your AI agent environment. Every application implements an MCP server over stdio exposing query_rql, get_findings, generate_remediation, and offscreen screenshot rendering:

claude_desktop_config.json / cursor_config.json:
{
  "mcpServers": {
    "cloudsecure-posture": {
      "command": "posturesecure-cli",
      "args": ["--mcp"]
    },
    "cloudsecure-graph": {
      "command": "graphsecure-cli",
      "args": ["--mcp"]
    },
    "cloudsecure-identity": {
      "command": "identitysecure-cli",
      "args": ["--mcp"]
    }
  }
}
02 / Headless CLI Reference & Formatting
CI/CD Gate Integration · SARIF & JSON Outputs
Command Description Sample Invocation
scan Run compliance or vulnerability assessment against target snapshot or path. posturesecure-cli scan --target ./cloud-state.json --benchmark cis-aws-v3.0
query Evaluate an arbitrary RQL query against local graph or inventory. policysecure-cli query "config from cloud.resource where ..."
remediate Synthesize reviewable, signed Terraform or CLI patch fix diff. codesecure-cli remediate --rule IAC_AWS_042 --out ./fix.patch
--format Control stdout output serialization (table, json, sarif, csv, csec). posturesecure-cli scan --format sarif > results.sarif
