Claude Desktop · Cursor · Windsurf · Gemini CLI Integration

07 ThreatSecure CDR threat_evaluate_cdr, threat_reconstruct_timeline eBPF syscall log correlation, CloudTrail anomaly detection, and MITRE ATT&CK mapping.
08 GraphSecure GRAPH graph_find_attack_paths, graph_compute_choke_points BFS toxic path discovery from Internet entry points to Crown Jewel data stores.
09 NetSecure ZERO TRUST net_analyze_flow, net_generate_network_policy VPC flow log reachability analysis and Kubernetes NetworkPolicy synthesis.

03 / Headless CLI Reference & Formatting
CI/CD Gate Integration · SARIF & JSON Outputs
Command Description Sample Invocation
scan Run compliance, security posture, or vulnerability assessment against target state. posturesecure-cli scan --target ./cloud-state.json --benchmark cis-aws-v3.0
query Evaluate an arbitrary RQL query against local graph or inventory. policysecure-cli query "config from cloud.resource where ..."
remediate Synthesize reviewable, signed Terraform or CLI patch fix diff. codesecure-cli remediate --rule IAC_AWS_042 --out ./fix.patch
--format Control stdout output serialization (table, json, sarif, csv, csec). posturesecure-cli scan --format sarif > results.sarif
--mcp Run as a standard JSON-RPC 2.0 stdio Model Context Protocol server. aisecure-cli --mcp
